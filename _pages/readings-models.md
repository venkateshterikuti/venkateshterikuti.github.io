# Open Source Models

High-quality open source models that demonstrate state-of-the-art capabilities and serve as valuable resources for research and development.

---

<div class="category-container">

<div class="resource-item">
<h3><i class="fas fa-robot"></i> <a href="https://huggingface.co/openbmb/VoxCPM-0.5B" target="_blank"><strong>VoxCPM-0.5B</strong></a></h3>
<p>Revolutionary tokenizer-free text-to-speech system that performs context-aware speech generation and zero-shot voice cloning. Built on continuous speech representations rather than discrete tokens, it overcomes limitations of traditional TTS systems. Features true-to-life voice cloning capabilities with only short reference audio clips, capturing timbre, accent, emotional tone, and pacing with remarkable fidelity.</p>
</div>

<div class="resource-item">
<h3><i class="fas fa-robot"></i> <a href="https://huggingface.co/collections/Qwen/qwen3-next-68c25fd6838e585db8eeea9d" target="_blank"><strong>Qwen3 Next Collection</strong></a></h3>
<p>Next-generation Qwen language models collection featuring improved architecture and enhanced capabilities over previous versions. Includes various model sizes optimized for different applications and computational constraints. Represents cutting-edge developments in large language model architecture with better reasoning capabilities and efficiency improvements.</p>
</div>
